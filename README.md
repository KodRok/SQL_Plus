# Финальный проект продвинутый SQL

Создана БД с 40 млн записями - PostgreSQL.

Выполняются тяжелые запросы (JOIN-WHERE).

Проводится анализ до оптимизации.

Затем создаются партиции и индексы.

Анализируется эффект оптимизции.

Также проведена демонстрация работы трансакций и блокировок (без дедлока).

Проект выполнен в двух вариантах: 

1) использованием pgAdmin и стандартными запросами для заполнения таблиц,
2) с использованием утилит заполнения таблиц на Java через IDE.
